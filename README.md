# AutoTyper

The installers appear in this folder after you build them:

| File | For | How to get it |
|---|---|---|
| `AutoTyper-SetupWindows.exe` | Windows 10/11 | double-click `Files\build_windows.bat` on Windows |
| `AutoTyper-macOS.dmg` | macOS 11+ | run `bash Files/build_macos.sh` on a Mac |

They are **not included yet**: they must be built on Windows and on macOS respectively
(or in the cloud with the GitHub workflow in `.github/`). Everything else - source code,
icons, tests, build scripts and the full documentation - is in the `Files` folder.
Start with `Files/README.md`.
